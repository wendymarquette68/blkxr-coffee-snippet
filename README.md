# BLKXR Coffee Maker — preview snippet

Black-and-gold coffee maker by WendstormXR for BLKXR, with a gold pressure gauge and a single BLKXR cup wordmark.

This is a test release for The Pod. Brewing runs a 12-second animated cycle with spatial audio. A separate selectable edition offers six body finishes. The current cup is stationary: pickup and steam following a held cup are still in development. DOSE, DOUBLE and GRIND are decorative controls.

Runtime bundles target Windows and Android using Unity 6000.3.21f1 and Creator SDK 4.0.29. The model has 24,742 triangles. This repository contains only the coffee runtime assets, loader and card; no private world source or account data.

## Install

Use the registered `blkxr-coffee-maker` snippet in the Creator SDK. Placement is controlled by its position, rotation and scale attributes. Use `edition="black-gold"` for BLKXR or `edition="selectable"` for six finishes.

Headset and multiple-user acceptance testing is pending. Do not treat this preview as the final giveaway package.
